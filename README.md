# Student-Service-Website

An interactive front-end web portal designed to streamline academic requests, student service inquiries, and live application status tracking.

---

## Status
Active Development (Work in Progress)

---

## Key Features

- **Service Request Interface:** Front-end submission system for student inquiries, academic forms, and administrative services.
- **Application Status Tracking:** Dedicated status views (`status.html`) built to display real-time progress and request outcomes.
- **Interactive UI Logic:** Vanilla JavaScript event listeners and DOM manipulation handling form validation and view transitions.
- **Modular Stylesheets:** Custom CSS architecture implementing clean typography, responsive layouts, and accessible component styling.

---

## Tech Stack

- **Markup:** HTML5 (Semantic Structure)
- **Styling:** CSS3 (Custom Responsive Layouts)
- **Scripting:** JavaScript (ES6 DOM Manipulation & Event Handling)
